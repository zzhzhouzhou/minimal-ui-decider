# Tests · Expected Behaviors

`tests/scenarios.md` 中每个场景（T-01…T-13）的**逐项可观察行为**。检查时逐条打勾；「禁止」项出现即为失败。

> 编号约定：场景前缀 **T-xx** 与规则 ID（C/M/S/Y）互不相干；本文件中出现的 S-xx 均指规则。

## 全局预期（所有场景）

- [ ] 先 Inspect 再动手：相关组件 / token / 依赖 / 模式被检查过（M-01、M-03）
- [ ] 复用现有能力优先于新建/新依赖
- [ ] 输出只含任务相关变更（M-06 最小 diff）
- [ ] 公共 API 未破坏（M-04）
- [ ] 数值取自 tokens（references/tokens.md），不随手填
- [ ] CRITICAL 底线未被突破（C-01…C-06）
- [ ] 用户输入安全渲染（M-07）
- [ ] 未默认引入新依赖（M-03）
- [ ] 未做无关重构（M-06）
- [ ] 声称完成前运行了可行的机械验证并出示证据（SKILL.md 工作流第 10 步）
- [ ] 未把 UI 开发变成问卷（仅在方案被实质改变时询问）

## T-01 · 修改现有按钮颜色

- [ ] 找到并 Inspect SaveButton 组件
- [ ] 确认颜色 token 位置（@theme / tokens.md）
- [ ] 只改动颜色相关行
- [ ] 禁止：替换组件架构、换图标库、重命名 props、顺手重构

## T-02 · 可搜索用户选择器

- [ ] 先判断 native select 是否足够并说明理由（10k → 不够）
- [ ] 使用 combobox 模式：`role="combobox"` / `listbox` / `option` / `aria-activedescendant`
- [ ] 键盘：↑↓ 移动、Enter 选择、Esc 收起
- [ ] 有 accessible name（label 在上方）
- [ ] 异步场景有 loading / empty / error 态
- [ ] 禁止：直接装新 UI 库；无搜索能力的选择器；无空态/错误态

## T-03 · 删除确认弹窗

- [ ] 复用已有 Modal/确认组件（若有）
- [ ] `role="alertdialog"` + 可访问标题
- [ ] 初始焦点落在安全选项（取消），危险动作不默认聚焦
- [ ] focus trap + Esc 关闭 + 背景锁滚动 + 关闭后焦点回触发器
- [ ] 危险操作红色 + 说明不可逆后果
- [ ] 进入动画（scale-in）与更快的退出；reduced motion 生效
- [ ] 禁止：无确认直接删除；弹窗打开时背景可滚动/可点；初始焦点落在删除按钮

## T-04 · 响应式侧边栏

- [ ] 窄屏侧边栏转换为抽屉/底部导航（不是简单 hidden）
- [ ] 抽屉有 dialog 语义、焦点管理、Esc 关闭
- [ ] 320px 无横向滚动；触控目标 ≥ 44px
- [ ] 核心导航在手机可达（C-06）
- [ ] 禁止：`hidden` 掉侧边栏导致功能失踪；hover-only 导航

## T-05 · 「更高级」

- [ ] 先做 Intent Translation 并优先 typography / spacing / hierarchy / material / subtle motion
- [ ] 使用项目 tokens 数值
- [ ] 装饰性动效 ≤ 一两处；尊重 reduced motion
- [ ] 禁止：默认玻璃拟态 + 渐变 + 发光；堆叠多个高级效果；新增依赖

## T-06 · 表单校验

- [ ] 每个字段有 label（非 placeholder）
- [ ] 错误在字段正下方：红字 + 图标 + 原因与解决方式
- [ ] `aria-invalid` + `aria-describedby` 关联
- [ ] 密码强度实时反馈 + 显示/隐藏切换
- [ ] 提交中禁用按钮；>300ms 才显示加载
- [ ] 禁止：placeholder 当 label；只靠颜色报错；提交后才一次性报错

## T-07 · 请求安装图标库

- [ ] 检查项目已有 inline SVG 图标能力
- [ ] 默认拒绝并说明理由（依赖成本 / 已有能力）
- [ ] 用户坚持时执行并报告 trade-off
- [ ] 禁止：未检查先安装；替换项目图标体系导致风格混乱

## T-08 · 深色模式

- [ ] 沿用 `.dark` 类 + `dark:` 变体（项目模式）
- [ ] 背景非纯黑、文字非纯白；层级越高背景越亮
- [ ] 深浅分别检查对比度 ≥ 4.5:1
- [ ] 深色层级用边框亮度表达
- [ ] 跟随系统 + 手动切换
- [ ] 禁止：简单反色；纯黑背景/纯白文字；忽略 reduced motion

## T-09 · 减少动效

- [ ] 保留服务反馈/层级/开合的动效
- [ ] 删除纯装饰动效
- [ ] 保留动效尊重 prefers-reduced-motion
- [ ] 只动 transform / opacity
- [ ] 禁止：为了「克制动效」把必要反馈也删掉（如按钮 press/loading）

## T-10 · 表格空态

- [ ] 空态 = 图标 + 说明 + 下一步动作
- [ ] 保持数字右对齐 + 等宽数字
- [ ] loading / empty / error 三态齐全
- [ ] 窄屏卡片化不被破坏
- [ ] 禁止：空数据白屏/留白无动作

## T-11 · 键盘审查

- [ ] 报告并修复所有键盘不可达的核心操作（C-01）
- [ ] 焦点清晰可见（focus-visible）
- [ ] 覆盖层 focus trap + Esc + 焦点复位 + 初始焦点规则
- [ ] 自定义控件符合原生键盘模式
- [ ] 禁止：`outline: none` 残留；修复后未复测

## T-12 · 过度动画

- [ ] 先跑复杂度测试（服务任务？降低其他复杂度？删除是否有损？）
- [ ] 指出全量粒子+聚光对层级/性能的损害
- [ ] 只对关键元素做克制增强；用户坚持则执行并报告 trade-off
- [ ] reduced motion 降级
- [ ] 禁止：不加判断直接全量加效果；装饰效果承载核心信息

## T-13 · 「更极简」

- [ ] 先按 `references/minimal.md`（Minimal Style Preset）转译意图，再动手
- [ ] 必要信息（label / 帮助 / 错误 / 反馈 / 状态）全部保留
- [ ] 删除的仅是装饰性 / 冗余元素，且逐项通过复杂度测试
- [ ] 高信息密度区域用层级 / 分组处理，功能未减少
- [ ] 颜色 / 边框 / 圆角 / 动效按语义保留（不教条归零）
- [ ] 可发现性与高频任务路径未受损（E-21）
- [ ] 复用现有组件与 tokens；最小 diff
- [ ] 禁止：强制全灰；删除 label / 说明文字；边框圆角动效一刀切删除；套同一模板忽略内容差异；删功能

## 通过标准

每个场景：全部 [ ] 命中，0 个禁止项触发。触发禁止项 = 回归失败，定位到具体规则（C/M/S/Y ID）并修复对应 Skill 文件后重跑；运行记录写入 `tests/regression-log.md`。
