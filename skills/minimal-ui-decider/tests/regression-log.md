# Tests · Regression Log

每次运行 `tests/scenarios.md` 行为回归后在此追加记录。**每个场景一行**；通过标准见 `tests/expected-behaviors.md`（全部预期命中、0 个禁止项触发）。

> 基线策略：v1.1.0 起，首个全量通过的那次运行记为 **回归基线（baseline）**；后续每次修改 Skill 后重跑对比基线，任何「基线通过 → 现在失败」的条目即回归，须修复对应文件后重跑。

## 记录格式

| 日期 | 基于 | 场景 | 结果 | 缺失/违背项 | 修复位置 |
| --- | --- | --- | --- | --- | --- |
| YYYY-MM-DD | Skill 版本 / commit | T-xx | ✅ pass / ❌ fail / ⚠️ partial | 具体哪几条预期未命中或禁止项触发 | 规则文件与行（fail 时必填） |

## 维护约定

- 修改 C/M/S/Y 规则、recipes 或反例后，**至少重跑受影响的场景**（如改 forms.md → T-02/T-06；改 accessibility.md → T-03/T-04/T-11）。
- 全量重跑（T-01…T-13）在每个版本发布前执行一次。
- 连续两个版本未变的场景，全量重跑时不可跳过。
